# 人设系统

人设系统是全局的「人格统一层」：它决定机器人怎么说话、怎么接情绪、怎么把记忆自然地带出来。
它和上下文、长期记忆、LLM、主动推送共用同一份设定，避免不同场景里像换了个人。

## 分组与覆盖顺序

人设按三级解析，优先级从高到低：

1. **单群人设**：群规则里绑定的角色；
2. **单账号人设**：账号设置里绑定的角色；
3. **全局默认人设**：`is_default=true` 的那一条。

后台「人设管理」可以新建、复制、导入/导出 JSON，并随时切换默认人设。

## 字段说明

| 字段 | 作用 |
| --- | --- |
| `name` | 角色名，会注入到 Prompt 和发送场景 |
| `description` | 基础档案：身份、年龄感、定位、一句话总览 |
| `personality` | 性格、情绪应对方式 |
| `speaking_style` | 句式、语气、表情、聊天习惯与示范对话 |
| `background` | 背景故事、兴趣、社交关系 |
| `hobbies` / `social_circle` | 单独抽出，方便在「主动分享」时取材 |
| `taboos` | 人设红线（禁止的说话方式与内容） |
| `red_lines` | 安全边界（违法、危险、隐私、心理危机等） |
| `system_prompt_template` | Prompt 模板，支持 `{name}` `{description}` 等占位符 |
| `style_settings` | 活泼度、表情频率、记忆唤起频率、回复长度、共情强度、主动性 |
| `life_schedule` | 作息表，被问到「在干嘛」时结合当前时间回答 |
| `emoji_keys` | 绑定到该人设的表情关键词 |

`system_prompt_template` 留空时使用 `backend/services/character_service.py` 里的默认模板，
它会在人设内容之后追加「聊天节奏」等系统级要求。

## Prompt 组装顺序

```text
system_prompt_template
  ├─ {description}      基础档案
  ├─ {personality}      性格
  ├─ {speaking_style}   说话方式
  ├─ {background}       背景
  ├─ {hobbies}          兴趣
  ├─ {social_circle}    社交
  ├─ {taboos}           红线
  └─ {red_lines}        安全边界
        ↓
  作用范围提示（全局 / 账号 / 群）
        ↓
  聊天节奏与自主性要求（CHAT_STYLE_HINT）
        ↓
  风格参数（活泼度、表情频率、回复长度、共情强度…）
        ↓
  当前时间 + 作息 + 上下文 + 长期记忆 + 搜索结果
```

## 记忆联动

人设里要明确「记忆是想起，不是检索」：

- 只在话题相关时顺势提一句，不无缘无故翻旧账；
- 一次对话主动唤起不超过 1–2 次；
- 拿不准时用试探语气，绝不编造；
- 不出现「根据记忆检索」「数据库记录显示」这类表达。

## 换人设

内置人设只是示例，替换方式有两种：

1. 后台「人设管理」直接编辑，或新建一条后设为默认；
2. 修改 `backend/common/character_defaults.py`，主要用于首次建库时的初始内容。

> 提示：已有数据库不会因为修改代码而覆盖你正在用的人设，避免误删用户的调校。
> 想恢复初始内容，可以照着 `docs/人设示例.md` 里的设定新建一条并设为默认。

## 风格参数

| 参数 | 说明 |
| --- | --- |
| `style` | `lively` 活泼亲近 / `gentle` 温柔安静 / `cool` 清冷理智 |
| `liveliness` | 活泼度 0–100 |
| `emoji_frequency` | 表情出现频率 0–100 |
| `memory_recall_frequency` | 主动唤起记忆的频率 0–100 |
| `reply_max_chars` | 回复目标长度（字） |
| `topic_fallback` | 冷场时是否自动抛话题 |
| `empathy` | 情绪共情强度 0–100 |
| `initiative` | 主动分享近况与想法的倾向 0–100 |

这些参数会以自然语言追加到 Prompt 末尾，不会直接暴露成配置项。
